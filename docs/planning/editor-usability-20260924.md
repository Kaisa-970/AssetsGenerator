# 节点工作台交互收口 · 2026-09-24

## 目标与范围

用户授权自主推进后，由主 agent 负责交付，子 agent 分别做产品审查、前端开发和独立测试。
本轮完成后交用户验收，不将“无人参与走查”当作用户认可，不新增模型或平台能力。

交付要求：

1. 输出展示独立组件化，来源核验和运行创建继续由原执行层掌握。
2. 中间网格可预览和 A/B 比较，实际外观事实与运行成功、QA 独立。
3. 参数未应用时不可静默使用旧配置创建新运行；跨节点与跨页保留草稿，显式应用或放弃。
4. 导入历史状态的画布与所选运行预览分别明确来源，不把历史完成徽标当作当前草稿状态。
5. 预览下拉与实际端口一致；无运行、无此节点、待执行、执行中和失败能够区分；图片可放大查看。

## 验收门槛

- 对修改行为有组件测试和浏览器交互回归；只读查看不得触发模型。
- 真实 HTTP + CPU 网格 fixture 覆盖生成、规范化与发布以及中间网格比较；不等同真实模型质量验收。
- 运行现有后端全量回归、前端测试与构建，对失败定位，不掩盖遗留问题。
- 独立审查参数状态与预览变更，修正发现的问题。
- 更新当前状态和中文操作指南，交付可复现启动/验收步骤与明确边界。

仓库外历史真实 GPU 记录保持不变；无必要不重复推理。保留原分支，不擅自合并或推送。
