# 节点编辑器结果预览首版

状态：首版已实现，小型 GLB 浏览器加载已验证；真实 DA3/Open3D 发布 GLB 查看已通过；纹理视觉与完整边界验收尚未完成。范围为已发布 GLB 的只读交互查看；不增加质量批准、材质修改或重新导出。

## 数据与运行绑定

预览入口来自选中运行的输出列表。点击时捕获 run ID、node ID、port 和输出 URL，页面标题显示该运行及节点；画布草稿后续修改不能替换预览模型。切换运行、切换输出或关闭弹窗必须中止旧请求并释放渲染资源，晚到响应不能覆盖新模型。

继续使用 `/api/runs/<run>/outputs/<node>/glb`，由服务校验运行归属、节点成功状态和完整 Artifact 闭包。浏览器不直接访问 Store 路径；HTTP 失败或损坏证据显示错误，不展示旧模型冒充成功。本地显式用户选择的历史成功结果不因草稿变化而失效。

## 渲染

使用 npm 固定版本的 Three.js 与 GLTFLoader/OrbitControls，由 Vite 打包随应用提供；不依赖 CDN。首版支持旋转、平移、缩放、重置视角，自动按模型包围盒取景，提供中性光照及坐标轴。保留模型材质和顶点颜色；不在预览阶段改写 GLB。

只渲染接口返回的 GLB；解析时拒绝外部 buffer/image URI，避免资产加载间接访问网络或服务器路径。允许 GLB 内嵌 bufferView 图片；首版明确拒绝 data URI，不静默忽略纹理加载失败。WebGL 不可用、解析失败或资源超限须有可见错误，保留原下载链接作为替代入口。

面板关闭时取消动画帧、断开 ResizeObserver、释放几何体/材质/纹理和 renderer；不因查看而写 BuildRun、提交人工决定、派发模型或更改任何 Artifact。

## 验收

- 浏览器实际加载小型自包含 GLB，出现 canvas、模型已加载状态，可重置视角。
- 模型含顶点颜色/内嵌纹理时保留外观；不将任意占位字节当有效 GLB。
- 输出请求失败、外部资源引用、WebGL 不可用分别显示错误。
- 快速切换运行/输出及关闭加载中的预览不会呈现旧模型，资源清理有测试。
- 原下载链接、固定运行图和 iframe 人工审查保持可用；查看不产生变更 API 调用。
- 使用至少一个已有真实发布 GLB 做浏览器 smoke，记录运行身份、加载结果和浏览器错误，不能仅以模拟 HTTP 用例代替。
