# 继续提取与阻塞操作提示

日期：2026-09-21。交互设计第 3.1、5.2 节首片；不关闭全部产品验收。

## 已实现

- 联合 mask 输出旁提供“继续提取”。后端只读核验所选不可变快照，保留分割及必要祖先，追加提取节点。
- 图片绑定沿用分割自身输入，包括上游缩放输出；不假设原图一定叫 `image`。
- 只有分割及祖先全部可复用、唯一新增提取待执行时，才允许确认方案。确认创建新运行并复核预检摘要；旧运行不变。
- 运行快照包含按节点投影的操作提示。页面核对 run ID 与 revision，缺失或过期提示不会启用恢复/重试。
- “请求核验并重试”只代表允许提交命令；输入、证据、旧进程与远程作业仍由命令端核验。提示投影不查询模型服务、不恢复运行、不授权重新推理。

## 验证

`tests/test_node_editor_continuation.py` 四项 CPU 测试包含真实 HTTP 链：GET 方案不写入，POST 带摘要创建成功，分割替身总计只执行一次，提取输出前景与透明像素正确，旧运行索引与快照字节不变。来源错配、mask 损坏和非法快照查询被拒绝。测试使用 CPU 分割替身，不是 SAM3 GPU 验收。

`tests/test_node_editor_actions.py` 十九项测试验证各状态、阻塞原因、远程未核实提示和纯只读投影。新增浏览器操作提示三项与两个既有相关用例共五项通过，覆盖过期/跨运行提示、忙碌禁用和重试拒绝后的原因显示。

集成验证：上述相关 Python 四文件合计 56 passed；六个浏览器文件合跑 48 passed，包含继续提取、预检、上传、自动编译、动作提示及既有编辑器回归。Ruff check/format、mypy 和前端生产构建通过。

## 边界

继续提取仅支持 `text_segmentation@1` 的可核实联合 mask，不自动继承人工决定。来源快照完整证据仍须可读，当前注册实现须能核对完整原计划；不能声称无关历史损坏已隔离。新运行显示固定运行图，不覆盖当前编辑草稿。

尚需完成：两次结果并列比较及明确选用、跨运行人工决定显式确认、来源证据局部隔离，以及首次主路径点击预算。没有在本轮重新运行真实 SAM3 或 SAM3D。
