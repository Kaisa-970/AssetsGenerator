# 已观测表面与 TSDF 融合诊断 v1

日期：2026-09-17。输入为前轮 scan65 的同一份 DA3 8 视图、392 分辨率预测。
本轮不运行新模型、不修改 Core 或默认参数，不产生正式质量阈值。

## 问题与方法

区分两件事：缺失表面是否在输入有效深度中存在，以及同一份深度经过多视图 TSDF
融合后是否仍能从原相机射线命中。该自洽性检查使用预测相机和预测深度作为参考，
不是与真实表面比较，不是 CameraRegistration gate，也不写入正式 render-back QA。

保持 voxel_length 固定为前轮 fine 的实际值；单视图融合也换算 ratio 保持相同实际长度。
运行已有 8 视图基线、只放宽 sdf_trunc 为原值 4 倍的多视图融合，以及 8 次独立单视图融合。
输入 RGB/mask/depth、相机、depth_trunc 均不变。单视图与多视图不能解释为相同约束强度，
仅用来定位相互融合前后表面是否被保留。

Open3D RaycastingScene 从原预测相机沿每隔 4 像素的射线查询网格首次命中。
只统计 mask 内正深度且低于 depth_trunc 的样本。方向的 camera-z 分量为 1，
因此 t_hit 与 z-depth 使用相同单位。记录射线命中率、无命中率和与输入深度相差不超过
基线 sdf_trunc 的比例；最后一个容差在所有组保持一致。
不做遮挡真值判断，不把不一致全部归因于模型，也不把射线命中当作准确重建。

证据和脚本位于 `<DATASET_ROOT>/tsdf-surface-diagnosis-v1/`：`run.py`、`run.log`、
`results.json`、每组 mesh/response 和 `maps/`。图例：绿色为命中且在容差内，
黄色为命中但与输入深度不符，红色为有效输入射线无网格命中，灰色不参与统计。

## 结果

已完成两组多视图网格射线检查（基线复用、宽截断新执行）与 8 次独立单视图 TSDF。
voxel_length=.00445052，基线 sdf_trunc=.01780207，宽截断=.07120826。
所有比例按有效采样像素数量加权；单视图行各自只对自己的输入视图检查。

| 对照 | 输入有效射线命中 | 命中且深度接近输入 | 无命中 |
|---|---:|---:|---:|
| multi_baseline | 95.69% | 88.29% | 4.31% |
| multi_wide | 98.60% | 81.41% | 1.40% |
| single_views | 89.83% | 89.82% | 10.17% |

基线多视图 30814 面，宽截断 29387 面。单视图射线命中率为 85.67%–90.87%，
命中后与本视图深度几乎全部一致；其缺失主要在物体轮廓、孔洞边缘等区域，
说明有限体素网格化和 mask 边界本身也会损失部分深度采样。
多视图基线增加了整体覆盖，但部分射线命中的表面与该视图深度不一致。
宽截断进一步增加覆盖，却使固定容差内的一致比例从 88.29% 降到 81.41%。
不能将更大截断距离输出的更完整外观等同于更高几何精度。

## 修正后的判断

用户检查输入照片后确认没有背面观测。因此背面开口符合本次输入覆盖，不能将其作为
DA3 重建失败的证据；后续质量检查应重点区分已观测区域的变形/破洞与未观测区域缺失。
DA3 使用学习先验估计可见深度，TSDF 融合这些表面；当前链路不执行完整物体的生成式补全。
局部平滑或表面连接不等于恢复真实背面。TRELLIS.2 等生成式 Shape Backend 可以推测
不可见结构，但生成结果不构成该结构在现实中存在的观测证据。

此前转台图中的“大面积缺面”不能直接解释为模型遗漏了大部分已观测表面。
有效预测深度范围内，基线约 95.69% 的射线仍能命中网格；背面开口与观察角度、
有限观测范围和不做生成补全的 TSDF 交付边界有关，但没有背面真值，不能给出归因比例。

当前支持的结论是：存在跨视图预测/融合不一致和边缘网格化损失；尚不支持
“DA3 是主要根因”或“换模型就能解决”。本轮使用预测深度作参考，无法证明它与真实物体一致，
遮挡关系也会影响首次命中，因此一致性变化只是诊断证据。

不修改默认 TSDF 参数、不启用自动补洞。下一步应明确交付目标：重建观测到的表面，
或生成完整闭合物体。前者需要扩大实拍角度覆盖并引入真实几何对照；后者需要单独的
completion 契约，并标注生成区域，不能称为纯重建。重力/摆放方向也应单独处理。

本轮无 Core 代码变更、无 GPU 模型重跑。真实 CPU TSDF 与射线诊断均已执行，
原始深度和基线网格摘要见 source.json。文档通过 git diff --check；未重跑全量代码测试。
