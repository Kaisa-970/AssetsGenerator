# 产品 CPU 图片路径浏览器验收

日期：2026-09-21。对应 `docs/product/node-editor-ux.md` 第 2.1 节。

## 范围与结论

正式 `node-editor --store` 无模型配置入口，默认打包 `cpu-image-editor` 模板，完成浏览器上传、显式启动及图片预览。使用真实 CPU EncodePng Adapter；不使用 Fake Backend、GPU、模型权重或模型服务。

本次输入上传完成到图片解码可见 **2.065 秒**，点击启动到图片解码可见 **2.056 秒**。该次观察低于 30 秒目标，但没有建立隔离负载基准，不据此保证任意硬件/输入性能。完整产品交互规范尚未验收通过。

## 浏览器回放与记录

1. 首屏模板标注 `CPU · 无需模型 · 配置可执行`。
2. 加载模板并确认替换画布，手动编译，进入运行页。
3. 图片来源切换浏览器上传，上传 PNG；界面说明点击启动前不执行模型。查询运行列表仍为空。
4. 点击启动新运行，等待 encode 完成，点击图片预览；确认图片完整加载且 naturalWidth=1024。
5. 刷新页面、重新进入运行页，服务端 BuildRun 与完成时逐字段相同，未触发新执行。
