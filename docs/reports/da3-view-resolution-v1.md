## 视觉观察与结论

`renders/` 展示正式 GLB。另从 reconstruction provenance 读取 native mesh，转换到各组
共同首张图 000000 的 camera frame（再绕 X 旋转 180 度用于显示），生成 `aligned-renders/`。
这只用于消除 world gauge 差异，不修改正式资产、不估计重力，也不是几何真值对齐。
诊断图使用固定正交方位、无光照面平均顶点色，各网格独立居中和缩放；不能作为像素级差异图。

对齐后四组整体形状相近：提高分辨率与加密视图能保留更多局部表面/颜色细节，但没有消除
大片缺失区域。16v-518 可作为本例后续诊断候选，不能宣称已通过资产质量验收或具有统计优势。
分辨率增加时有效深度比例没有单调上升，说明“更多像素”并不自动带来更多高置信有效观测。
新增视图没有扩大角度范围，因此不应期待仅靠本对照恢复未观测的背面。

之前正式 GLB 显示的朝向差异，在参考相机对齐后显著减小：这支持 DA3 world 的全局 gauge
变化与固定 up=-Y 约定会影响外观摆放。不能将这类旋转差异直接当成几何重建失败。

## 下一步

不据本例直接换模型或启用 completion。优先区分已观测区域的融合缺面和未观测表面：
检查各视图点云在 mask 内的重合、遮挡关系，并获取扩大角度覆盖的观测；
独立设计可追溯的 up-axis/orientation policy。相对深度/相机精度仍需有真值对照才能归因。
保持 Backend 默认值，正式人工 keep/improve/reject 仍 pending。

本轮未改 Core 运行代码，无包安装、无 PyTorch 下载。GPU/CPU 四组实测及发布证据检查已执行；
未重跑全量代码测试，沿用 337 项基线。文档通过 git diff --check。
