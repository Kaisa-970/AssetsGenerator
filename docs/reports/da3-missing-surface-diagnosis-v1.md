# DA3 / TSDF 缺面诊断 v1

日期：2026-09-17。范围：DTU scan65 的既定 8 视图、DA3-Base、process_res=392。
本轮为诊断，不修改 Backend 默认配置，不实现 Phase 5 registration gate。

## 方法与证据

在仓库外脚本中调用现有 DA3 runner，捕获同一次推理的原始 depth/confidence，
保存原分位过滤结果和取消置信阈值后的深度；保持相机与 RGB/mask 不变，分别执行
Open3D fine profile（voxel ratio .005、sdf ratio .02、depth trunc ratio 3）。
证据与脚本：`<DATASET_ROOT>/da3-diagnosis-v1/` 的 `run.py`、`raw-*.npz`、
`da3-response.json`、`coverage.json`、`fuse.py`、`fusion-results.json`、`renders/`。
关闭过滤会轻微改变有效深度中位数，因此两组实际 voxel 分别为 .00445052 和 .00446194；
不是严格固定物理 voxel 的单变量对照，不据此精确量化过滤的几何收益。

另下载与输入相同镜像 revision 的 `scan65/cameras.npz`，用 world_mat 分解数据集相机，
通过相机中心的 proper similarity alignment 消除全局旋转、平移和相对尺度。
不把此离线诊断当成 registration gate，不生成像素级 QA 通过结论。

## 事实

- 原始预测在所有 8 张图的 mask 内有效深度覆盖为 100%；不是“模型直接没输出深度”。
- 默认过滤后 mask 内有效比例为 89.97%–96.81%。全图 40 分位过滤并不意味着删掉 40% 的物体。
- 过滤版 30814 面、2972 边界边；无过滤版 37156 面、4460 边界边。诊断图仍有主要缺面，
  无过滤版额外出现离群表面，导致自动包围盒显著扩大。图中缩小是取景范围变化，不是实际尺度缩小。
- 相机中心对齐 RMSE / 数据集相机中心 RMS 半径为 1.525%；旋转差 0.836°–1.766°。
  这只描述本样例相对姿态，不证明深度准确或相机注册达标。
- 估计 fx 为 2779.7–2938.5，数据集约 2892.3；估计 fy 为 3269.5–3424.9，数据集约 2883.2。
  检查 adapter 的内参还原仍按 upstream resize/crop 约定；没有在本轮发现矩阵求逆或轴缩放实现错误。
- 使用数据集内参替换估计内参后输出 32038 面、2318 边界边，主要缺面仍在。
  该对照保留预测深度与外参，且将数据集微小 skew 置零以符合 Open3D pinhole 契约，
  不是完整真值相机条件重建，也不能据边界边减少宣称质量提升。
- 相邻选中视图的原始深度反投影后，在目标 mask 内采样的相对深度差中位数为
  0.88%–5.29%，90 分位为 2.38%–22.17%。未做遮挡门控，这只是几何不一致诊断，
  不能把全部差异归因于模型深度错误，也不能当作 render-back QA 指标。

## 观察与结论

取消过滤以及替换内参均未恢复完整表面；没有证据支持直接换模型即可解决。
相机相对姿态总体接近参考，但内参差异、跨视图深度不一致和有限视角仍值得关注。
有效深度存在不代表深度正确：不同视图的表面错位仍会影响 TSDF 的零交叉与表面连续性。
当前不能确定缺面主要由模型、遮挡/视角覆盖还是融合参数造成。

默认 `up_axis=-Y` 是世界坐标约定，DA3 world 没有提供物体重力方向。
不能把倒置外观直接归因于模型；也不能仅凭该单例将默认轴翻转并推广到全部资产。

下一轮优先固定 fine profile，做 8/16 视图与 392/518 分辨率对照，并分别展示
mask 内逐视图点云与融合表面，定位可见表面是否在融合前已经错位。
需要有遮挡处理或真值深度对照后，才能更强地归因。暂不启用 completion 掩盖问题。

本轮未修改 Core 代码，真实 DA3 推理与三次 CPU TSDF 诊断均已执行；相关输出未作为正式
AssetRelease 发布。沿用前一轮 337 项测试基线，不声称本轮重跑全量测试。
